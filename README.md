# Cafe Management & Business Website

A modern, responsive, full-stack cafe website and admin dashboard.

## Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS, shadcn/ui, Framer Motion
- **Backend:** FastAPI, Python, SQLAlchemy
- **Database:** PostgreSQL
- **Image Hosting:** Cloudinary

## Project Structure

- `/frontend` - Next.js application (Public UI & Admin Dashboard)
- `/backend` - FastAPI application (REST APIs, DB Models)
